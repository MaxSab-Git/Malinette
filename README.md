# Malinette
A Unit Test program using .mali files as source. Mainly made for Linux, but should compile fine with most POSIX compliant systems including, in theory, MacOS.</br>
This program has mainly been tested on the WSL version of Linux Ubuntu and on Windows, other systems may not be as supported as claimed.</br>
The Windows port is quite dirty and finicky, but it works, you have been warned.</br>
